## Decisões técnicas

- **Protocolo ATmega→ESP01**: frame binário com SOF + LEN + TYPE + PAYLOAD + CRC16-CCITT.
  Motivo: permite crescer o conjunto de variáveis (THD, freq, flicker) sem
  quebrar parsers antigos; CRC detecta ruído na UART 5 V↔3,3 V.
- **Broker MQTT** (Mi 8 Lite, 192.168.1.10) como desacoplador ESP01/ESP32.
  Motivo: Home Assistant já usa o mesmo broker; se ESP32 cai, broker buffera.
